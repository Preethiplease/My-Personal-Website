# Personal Portfolio Website

This is my personal website built to showcase my projects, skills, and learning journey in software development.  
The site is hosted using **GitHub Pages**.

🔗 [Live Site](https://preethiplease.github.io/My-Personal-Website/index.html)


---

## Overview

This website serves as:
- A personal portfolio
- A place to document my projects and learning
- A simple, clean web presence built from scratch

The focus is on clarity, structure, and strong fundamentals rather than heavy frameworks.

---

## Built With

- **HTML5** – structure and content  
- **CSS3** – layout and styling  
- **JavaScript** – basic interactivity  
- **GitHub Pages** – hosting and deployment

---

## Features

- Responsive layout *(currently optimised for desktop)*
- About Me section
- Projects section
- Music section
- Interactive Snake game and sandbox
- Contact and social links
- Clean, minimal design

---

## Deployment

This site is deployed using **GitHub Pages**.

Steps used:
1. Push code to the `main` branch
2. Enable GitHub Pages in repository settings
3. Select the root folder as the source
4. Access the site via the GitHub Pages URL
